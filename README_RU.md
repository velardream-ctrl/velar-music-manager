# VELARDREAM RECORDS — главная страница и планы

**Состояние на 9 ноября 2026:** GitHub Pages сборка опубликована; GitHub на скриншоте владельца подтвердил `DNS check successful` для `velardream.com`; пункт `Enforce HTTPS` стал доступным, **включение владельцем ещё не подтверждено**. Публикацию каждой новой версии и реальную работу сайта отдельно подтверждаем после CI/открытия на телефоне.

## Что находится в этом публичном репозитории
- Главная витрина VELARDREAM RECORDS с оригинальным логотипом владельца (assets/velardream-records.jpg), меню и четырьмя секциями о будущих артистах, релизах, жанрах и проекте.
- Текстовый заголовок, description, alt изображения, обычные HTML-ссылки и метаданные для будущего SEO.
- `noindex` до решения о публичном запуске. **Сайт публично доступен по ссылке и не защищён паролем.**
- `/app/` — отдельная пустая заглушка без авторизации и без личных данных.
- Service Worker сохраняет **только публичные ресурсы**. Никаких приватных текстов/контактов/ключей здесь нет.
- `firestore.rules` — deny-all черновик, пока не применён к Firebase.
- Автоматические проверки: `npm test`.

## Что будет дальше
- Страницы отдельных артистов с темами и фото, записи/релизы, жанры и подборки. См. [архитектуру](docs/MUSIC_DOMAIN_MODEL_RU.md) и [план главной](docs/HOMEPAGE_BLUEPRINT_RU.md).
- Личный каталог и Lyrics Studio только после получения последней версии VMM Apps Script, отдельной Firebase Auth и строгих Firestore Rules. Не переносить личные данные в публичные файлы.
- IndexedDB + очередь изменений для настоящего офлайн-редактирования песен, синхронизация между устройствами после восстановления сети, отдельные тесты конфликтов.
- Внешние стриминговые плееры потребуют интернет и соблюдения правил соответствующих сервисов.
- По согласованию владельца после запуска: убрать `noindex` только с публичных страниц, добавить sitemap, Google Search Console, проверяемые метаданные релизов.

**Важно:** никакие личные релизы, контакты и тексты песен в данный репозиторий не помещены. GitHub Pages и Cloudflare DNS уже настроены пользователем, но полный тест HTTPS/PWA на устройстве ещё не завершён. Журнал и резервные копии находятся в приватной папке Google Drive.
