# VELARDREAM RECORDS — сайт и закрытая мастерская

**Состояние: 9 ноября 2026.** GitHub Pages опубликован на `velardream.com`. Визуальная главная согласована владельцем. GitHub CI и публикация последней версии прошли успешно.

## Публичная часть
- Лейбл VELARDREAM RECORDS, стилизованная звёздная главная, фирменный кристалл, артисты / релизы / жанры / о проекте.
- Центральное оформление и шрифты согласованы; не менять без новой просьбы.
- Публичная главная сохраняет `noindex` до запуска индексации. `noindex` — **не** пароль.
- Публичный Service Worker содержит только статические активы; тексты и контакты в него не помещаются.

## Закрытая часть: `/studio/`
- Подготовлен отдельный интерфейс музыкального менеджера без ссылки из публичной навигации. Адрес известен владельцу, но сама HTML-страница технически доступна любому, как и любая страница GitHub Pages. **Пользовательских данных и секретов в её исходниках нет.**
- Перед показом закрытой области требуются одновременно Google Firebase Authentication и разрешающий документ `vmm_admins/{uid}` в Firestore.
- Пока Firebase web config не задан, интерфейс безопасно блокирует вход и показывает сообщение о настройке. **Google-вход ещё не подключён**, данные в Firestore не импортированы.
- После подключения предусмотрены списки текстов, редактор, базовая печать A4/PDF, пункты для каталога, фонограмм, площадок, контактов, рассылок и журнала. Полная функциональная миграция прежнего VMM и Lyrics Studio v1.3 ещё не завершена.
- Правила `firestore.rules` подготовлены, **но не развернуты в Firebase**. Создать совершенно отдельный Firebase-проект VELAR; не использовать Sanastoyhteisö.
- Приватная резервная Google Sheet сохранена в папке журнала проекта. Оригинал оставлен без изменений.

**Следующий этап:** подключить новый Firebase (Auth с Google, Cloud Firestore, админский UID), проверить разрешения и запрет чужого аккаунта; затем безопасно импортировать тексты с сохранением версий и исходных дат. Подробно: [docs/PRIVATE_STUDIO_SETUP_RU.md](docs/PRIVATE_STUDIO_SETUP_RU.md).

## Дальнейшая разработка
[Артисты и музыкальный каталог](docs/MUSIC_DOMAIN_MODEL_RU.md), [структура главной](docs/HOMEPAGE_BLUEPRINT_RU.md). Настоящий offline-first редактор, синхронизация и обработка конфликтов требуют отдельного тестирования. Внешние аудио/видео требуют интернет.

**Внимание:** сам сайт и его исходники остаются публичными; защищена должна быть база. Не коммитить тексты песен, контакты, токены доступа, ключи сервисных аккаунтов и личные данные.
