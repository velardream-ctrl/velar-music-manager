# VELAR DREAM — инструкция к стартовой оболочке

Состояние: **репозиторий существует**, исходники загружены 09.11.2026. CI проверяет безопасные статические файлы. **GitHub Pages ещё не включён и DNS в Cloudflare не настроен; публикация на velardream.com не подтверждена.**

## Что готово
- Общедоступная техническая стартовая страница с `noindex`; личный `/app/` — пока только пустая публичная заглушка.
- PWA manifest, иконки и Service Worker, ограниченный публичными файлами. Установка и автономное открытие ещё требуют реального теста на HTTPS.
- Код ES5 для совместимости со старым iOS, статические проверки `npm test`.
- `firestore.rules` с запретом всех чтений и записей; пока не развёрнут в Firebase.
- Заложена модель музыкального лейбла с отдельными артистами, треками, релизами, жанрами и тематическими плейлистами: [docs/MUSIC_DOMAIN_MODEL_RU.md](docs/MUSIC_DOMAIN_MODEL_RU.md).

## Что НЕ готово
- Настроенный GitHub Pages и сертификат HTTPS на `velardream.com`.
- Авторизация, перенос закрытого каталога, Lyrics Studio, офлайн-редактирование текстов, синхронизация между устройствами.
- Публичные страницы артистов и медиа. Никаких личных данных и песен в данном публичном репозитории **нет**.

## Следующий шаг настройки (одна публикация на настоящем домене)
1. Открыть репозиторий → **Settings → Pages**.
2. В разделе Build and deployment выбрать **Deploy from a branch**, ветку **main**, папку **/(root)**, Save.
3. После включения Pages указать **Custom domain** `velardream.com` и сохранить.
4. Лучше верифицировать свой домен в GitHub через собственную TXT-запись, которую GitHub покажет в интерфейсе (не угадывать её).
5. **После настройки домена в Pages** добавить в Cloudflare DNS четыре IPv4-записи A для корня `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Для `www` можно задать CNAME `velardream-ctrl.github.io`. На первоначальной проверке записи — **DNS only**, без проксирования.
6. Дождаться корректного HTTPS и пройти на телефоне тест страницы, PWA и офлайна. Это не означает, что личный каталог уже перенесён.

**Важно:** файл `CNAME` сам по себе не включает пользовательский домен в настройках GitHub Pages. `noindex` не скрывает данные от посетителей. Не публиковать тексты, контакты, токены или пользовательскую информацию в этом репозитории. Не удалять существующие DNS-записи почты (MX, TXT) без проверки.

GitHub Pages для этого публичного репозитория — бесплатный. Домен принадлежит владельцу и оплачен отдельно в Cloudflare Registrar.

## Дальнейшая разработка
Получить точную актуальную версию VMM из Google Apps Script, сохранить неизменный дизайн и Lyrics Studio. После отдельной настройки безопасного Firebase Auth/Firestore импортировать приватные данные из проверенной резервной копии. Реализовать IndexedDB, очередь офлайн-изменений и подтверждённую синхронизацию; затем согласовать и опубликовать индивидуальные страницы артистов. Все RUN и контрольные точки сохранять в приватной папке Google Drive проекта.
