# VELAR — безопасная стартовая оболочка для velardream.com

Версия 0.0.1 (09.11.2026). Публичный домен пользователя уже зарегистрирован. Это **не полный VMM** и не замена последней версии Google Apps Script. Здесь нет личного музыкального каталога, текстов, Firebase-настроек или аккаунтов.

## Что уже готово
- Начальная публичная заглушка, `noindex` и канонический адрес.
- Заглушка `/app/` без личных данных и без имитации авторизации.
- Service Worker, который кэширует **только заранее перечисленные общедоступные ресурсы**. После первого успешного открытия страницу можно открыть без сети в поддерживаемом браузере.
- PWA manifest, иконки, ES5 JavaScript для совместимости со старым iOS.
- `CNAME` для GitHub Pages и `.nojekyll`.
- Черновой `firestore.rules`, запрещающий **всё** до полной проверки авторизации. Никакой Firebase-проект не создан, файл не опубликован как Firestore Rules.
- Тесты без сторонних зависимостей: `npm test`.

## Что не готово
- Отдельный GitHub-репозиторий, GitHub Pages, настройки Cloudflare DNS/HTTPS.
- Подключение Firebase Auth, офлайн-редактирование личных песен, синхронизация между устройствами.
- Перенос последней версии VMM с девятью разделами и Lyrics Studio; здесь для этой цели нет достаточных актуальных исходников.

## Ближайшие действия
1. Владелец один раз создаёт **пустой публичный** GitHub repo `velardream-ctrl/velar-music-manager` через `https://github.com/new` — подключённые действия GitHub позволяют редактировать существующие репозитории, но не создавать новые.
2. Ассистент загружает в него этот пакет через GitHub-коннектор, проверяет коммиты и тесты.
3. В GitHub репозитории Settings → Pages → Deploy from a branch → `main` / `(root)`, затем Custom domain `velardream.com`.
4. В GitHub Settings → Pages пользователя **сначала** желательно подтвердить домен через TXT у Cloudflare, чтобы защитить от domain takeover.
5. Только после привязки домена к Pages в Cloudflare DNS настроить `A @ → 185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (все четыре), при необходимости `CNAME www → velardream-ctrl.github.io` (DNS only). Не удалять другие записи без проверки, не менять MX/письма.
6. Дождаться HTTPS, затем проверить онлайн и офлайн. **Личные данные не вводить** до настроенной авторизации и проверки Firestore Rules.

## Почему это безопасная временная заглушка
Бесплатный GitHub Pages публикует исходники. Неразглашение ссылки и `noindex` не являются защитой. Поэтому здесь физически нет закрытых данных. Личные тексты после миграции будут доступны лишь в защищённой базе, IndexedDB на доверенных устройствах и под авторизацией. Статическая заглушка видна любому посетителю, знающему URL.

Текущие требования и журнал: Google Drive `VELAR_MIGRATION_2026-11-09_RUN_LOG`; архитектура предусматривает будущие `/music`, `/video`, `/radio`, `/community`.
