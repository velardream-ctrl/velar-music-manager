# RUN-194 — DJ Velar AI + только опубликованный музыкальный каталог
Дата: 17.11.2026

## Задача
После успешного ответа Llama 3.1 8B через закрытую лабораторию подключить модель к РЕАЛЬНЫМ названиям/исполнителям/категориям песен, без выдуманных ссылок и без доступа к закрытым 280 записям репертуара.

## Что реализовано
- `studio/ai-public-catalog.js` — отдельная read-only обёртка над ЕДИНСТВЕННЫМ публичным документом `vmm_public_pages/landing` (только status=published и schemaVersion=1), читаемым по `get({source:'server'})` только по явному действию в лаборатории. Никаких запросов к `vmm_catalog`, к черновикам, записям пользователей и текстам песен.
- Из публичного документа выбираются только visible===true жанры, темы, языки, альбомы и профили артистов; для каждой композиции требуются непустое название и проверенная официальная ссылка Spotify/YouTube/Apple Music. Ссылки проверяются по разрешённым форматам, очищаются от Spotify и YouTube лишних параметров. Повторы удаляются по provider+URL.
- На вопрос модель получает не более четырёх опубликованных записей — названия, исполнитель и публичная категория. Сами URL и идентификаторы в запрос модели не передаются. Общая длина сообщения не превышает существующий серверный лимит 500 символов. Поиск предварительно ранжирует записи простыми правилами на устройстве; это НЕ полноценный смысловой поиск по всем 280 песням.
- `studio/ai-lab.js`: новая **выключенная по умолчанию** опция «Подбирать из реально опубликованных песен VELARDREAM». При включении проверяет именно публичный снимок из Firebase, показывает короткий список проверенных ссылок отдельно от текста нейросети, а затем запускает прежний защищённый запрос к Cloudflare Worker. Если опубликованных композиций нет, запрос к модели с якобы знакомыми песнями не выполняется.
- Публичный DJ Velar пока не вызывает ИИ, Cloudflare Worker не менялся (не надо заново вставлять код или менять секрет). Медиа, радио, кристалл и Firestore Rules оставлены неизменными. Секрет и вопросы не записываются в базу или localStorage.

## Как проверить
1. На iPhone открыть Studio → Главная страница → Помощник VELAR → Лаборатория DJ Velar AI.
2. Ввести URL своего Worker и секрет. Поставить галочку «Подбирать из реально опубликованных песен VELARDREAM».
3. Спросить «Что послушать о любви?» либо про космос / грусть. После ответа посмотреть отдельный блок проверенных ссылок и текст модели. Ссылки должны вести только на реально опубликованные Spotify, YouTube либо Apple Music.
4. Сравнить рекомендации с открытым сайтом. Если название из ответа ИИ отсутствует среди проверенных ссылок, не считать его достоверным: пока модель отвечает текстом свободно. Следующий этап — структурированный ответ с выбором только подтверждённых ID.
5. Снять галочку — прежняя свободная тестовая беседа должна работать без дополнительного чтения Firebase.

## Ограничения и будущий этап
- Содержимое открытой страницы может отражать лишь часть 280 песен. Неприкреплённые и не опубликованные песни намеренно исключаются. Это ограничение точности, но защищает приватные черновики.
- На текущем Worker текст LLM не подвергается строгой валидации названий; источником истины остаётся отдельный список проверенных официальных ссылок. Публичное размещение ИИ не разрешено.
- Следом: структурированные ответы по утверждённым song IDs, whitelist команд, ограничение частоты/стоимости и проверка старых iPad. Никогда не передавать секрет владельца в публичный чат.
