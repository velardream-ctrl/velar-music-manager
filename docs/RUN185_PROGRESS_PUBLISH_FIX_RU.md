# RUN-185 — исправление публикации статистики (17.11.2026)

## Симптом
На iPhone в Studio публикация статистики блокировалась: «Заполненных ссылок не может быть больше общего числа», кнопка публикации недоступна, локальная копия черновика ожидает облачной синхронизации.

## Причина
Разные единицы измерения: 280 композиций, но до трёх ссылок на каждую (Spotify / Apple Music / YouTube). Для 280 песен потенциально 840 ссылок. Пример из обзора: 261 + 261 + 160 = 682 из 840, то есть около 81,2%.
Ошибка возникает, если в поле «Всего возможных ссылок» пользователь внёс число песен (280) вместо ссылочных слотов (840). Схема правильно запрещает completed > total, но редактор недостаточно объяснял единицы.

## Исправления
Studio → Главная страница → О проекте: поле знаменателя поясняет «число песен × 3», отдельная кнопка вычисляет значение из метрики «Композиции в каталоге».
Проверенный узкий случай ошибочного знаменателя (total совпадает с числом песен, completed не превышает songs × 3) корректируется в копии данных при восстановлении и синхронизации локального черновика; любые другие некорректные данные по-прежнему отклоняются.
При ручном сохранении черновика обнаруженное расхождение исправляется сначала в редакторе с предупреждением, затем требует отдельного повторного нажатия «Сохранить черновик». Никакой обход защиты Firestore или автоматической публикации.
Существующие значения отдельных показателей, черновики, приватные песни и настройки сайта не удаляются.

## Действия владельца
1. Сначала скачать резервную копию несинхронизированных изменений, если отображается соответствующее сообщение.
2. В Studio → Главная страница → О проекте проверить «Ссылок заполнено» и «Всего возможных ссылок». Для 280 песен и трёх площадок — 682 / 840.
3. Сохранить черновик, убедиться в облачной синхронизации и затем отдельно опубликовать.
4. Не применять «Обновить из базы», пока есть несинхронизированные правки.

## Безопасность
Нельзя подменять 840 общим количеством композиций, и 81% — это заполненность ссылок, НЕ готовность сайта. В будущем обновлять инструкцию восстановления вместе с кодом.
