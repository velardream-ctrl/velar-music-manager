# RUN-075 — Язык названия, каталог Firestore и музыкальная вселенная

Дата: 2026-11-11. Пользователь прислал 10 фирменных аватаров DJ Velar, подтвердил подключение помощника (RUN-074), затем поручил массово заполнить языки названий композиций без необходимости сначала добавлять тексты всех песен.

## Найденные источники
- **Рабочий источник данных** VELAR Music Manager — защищённая коллекция `vmm_catalog` Firebase Firestore; только Google-администратор может читать/изменять её, по действующим `firestore.rules`.
- Резервные Google Sheets от 9 ноября 2026: `VELAR_VMM_SOURCE_BACKUP_2026-11-09_READ_ONLY_COPY`, вкладка «Каталог» 278 названий (173 с кириллицей, 105 латиницей), **столбца языка нет**. В исторической вкладке `VMM v1.2 · Тексты` язык уже есть в колонке E, но только для части записей с текстами. Копии не менялись и **не использовались как live Firestore**.
- Примеры неоднозначностей: латинские названия `Lux Obscura`, `Requiem Aeternam`; урду/хинди в латинской транслитерации `Noor-e-Dil`; вымышленные `CRAZY BOBR` и много английских инструментальных названий. Нельзя автоматически приравнивать латиницу к английскому или язык названия к языку исполнения.

## Реализованная безопасная автоматизация
- `studio/title-language.js`: автономный ES5-детектор названий и проверочный интерфейс **Studio → Главная страница → Языки песен**.
- Нажатие «Проверить языки каталога» анализирует уже загруженный закрытый `vmm_catalog`, не создаёт публичных запросов/пишущих операций. 35 строк за раз; отдельный фильтр неоднозначных, возможность вручную выбрать язык названия. Русская кириллица рассматривается как уверенное предположение в рамках данного каталога. Некоторые именные/латинские и смешанные названия помечаются для проверки, а не записываются неверно.
- После отдельного подтверждения администратора **«Сохранить подтверждённые языки»** изменяются только три поля записи `vmm_catalog`: `titleLanguage`, `titleLanguageMethod`, `titleLanguageUpdatedAt`. Существующее поле `titleLanguage` (включая неизвестные значения) не перезаписывается. Тексты `vmm_lyrics.language`, UPC, ISRC, ссылки и сами записи не меняются. Пакеты по 200 записей с подтверждённой Google-сессией администратора; типовая одноразовая операция сотен записей, не ежедневная нагрузка.
- **«Подключить языки к созвездиям (черновик)»** копирует только `title,artist,provider,url` с валидированным Spotify/YouTube direct-track URL в уже существующее `genres.languages.entries[].tracks`. Используются **только сохранённые** в live-каталоге языки, без автопубликации и без доступа посторонних к Firestore; сохраняются ручные привязки и удаляются дубликаты. После этой кнопки требуется привычное **«Сохранить черновик» → «Опубликовать»**.
- Язык **названия** — не доказательство языка **текста или вокала**. При подготовке поискового SEO в будущем отдельно сверять язык исполнения; до того пользователь может вручную скорректировать все сомнения.
- Новых публичных Firestore listener, услуг перевода, ML API, платного хостинга и Firestore Rules нет. GitHub Pages и сознательный `noindex` неизменны.

## Запуск владельцем
1. Перейти в https://velardream.com/studio/ → «Главная страница» → «Языки песен».
2. Войти Google-аккаунтом администратора и выбрать «Загрузить каталог» при необходимости.
3. Нажать «Проверить языки каталога», посмотреть числа и фильтр «Только требующие проверки», поправить сомнительные.
4. Нажать «Сохранить подтверждённые языки», подтвердить запись в защищённый Firestore; проверить статус успеха.
5. Нажать «Подключить языки к созвездиям (черновик)».
6. Нажать «Сохранить черновик» → «Опубликовать»; открыть https://velardream.com/#languages.
7. Для латинского, португальского, хинди и других ещё не включённых миров сначала вручную создать соответствующий язык на той же странице и сверить названия.

Важно: в текущем диалоге **нет прямого авторизованного Firestore-коннектора**, поэтому SQL/REST bulk update от имени владельца не выполнялся; механизм написан и проверен автоматическими тестами, но заполнение **живой базы и публикация самого списка песен произойдут только после действий администратора**. Не заявлять обратное.
