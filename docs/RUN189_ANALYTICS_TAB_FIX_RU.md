# RUN-189 — Пустая вкладка статистики на iPhone (17.11.2026)

**ПРОБЛЕМА:** В Studio → Главная страница → «Статистика посещений» кнопка активна (подсвечена золотом), но форма полностью пустая. Скриншот владельца с 19:26, тогда как кнопки сохранения и публикации видны.

**АНАЛИЗ:** вкладка объявлена в HTML, но studio/landing-editor.js до обновления использовал прежний URL v=46&fix=185, по которому iOS/PWA мог держать старую копию без обработки analytics. В объекте подписей tabs не была зарегистрирована аналитика.

**ИСПРАВЛЕНО:** в studio/index.html и sw.js добавлен отдельный query-параметр analytics=189 для редактора и новая ревизия двух SW-кэшей. В JS добавлена регистрация вкладки, её заголовок и безопасный вывод сообщения об ошибке вместо полного молчания. Файлы базы, Firestore Rules, каталог, медиаплееры и данные опубликованного сайта не менялись.

**ПРОВЕРКА:** tests/test-analytics-tab.mjs + общий npm test, PR — см. историю Git. Отдельно необходимо открыть новую версию Studio на iPhone и убедиться, что формы аналитики видны.

**ДЕЙСТВИЯ:** Не нажимать «Обновить из базы» / «Вернуть опубликованную версию» при локальных несинхронизированных изменениях. Открыть Studio заново после развёртывания, нажать «Статистика посещений», проверить галочку GA4. После выбора — «Сохранить черновик» → «Опубликовать». Если установленная PWA остаётся старой, временно открыть Studio в обычной вкладке Safari; не удалять PWA, чтобы не терять localStorage / offline-черновик.
