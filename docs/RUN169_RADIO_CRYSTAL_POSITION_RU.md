# RUN-169 — первое появление VELAR RADIO рядом с кристаллом
Дата: 17.11.2026. Скриншот владельца: начальное положение в верхнем правом углу закрывает меню. Цель — размещать круглый плавающий логотип справа от кристалла VELARDREAM, по центру изображения, не закрывая навигацию.

## Поведение
- Используются фактические размеры и координаты hero-crystal-link и site-header; позиция фиксируется относительно окна после первого появления. Нет привязки по жёсткой высоте экрана.
- Отступ от кристалла 8–28px по ширине окна; круг 68px. Ограничены границы экрана и верхний край меню + 16px. Без видимого кристалла — безопасное положение в видимой части экрана.
- При изменении ширины экрана до ручного движения — переустановка рядом с кристаллом. При Safari scroll/смене высоты без изменения ширины — позиция не скачет.
- После самостоятельного перетаскивания/перемещения стрелками координаты сохраняются в текущем сеансе при раскрытии, сворачивании, повороте. Не добавлено сохранение в localStorage (до этого его не было).
- Плеер, YouTube autoplay/Next, iframe, управление в Studio, уровень свечения по умолчанию 20%, анимации и доступность кнопок не изменялись.
- Сохранена корректная сторона раскрытия мини-плеера.
