# Шаблон записи нового RUN

Скопировать этот блок в конец [журнала](WORK_ACTIVITY_LOG_RU.md) перед началом работы.

```markdown
### YYYY-MM-DD — RUN-NNN — НАЧАЛ
- Симптом (как воспроизвести):
- Контекст: последняя версия, устройство/браузер, данные (без секретов):
- Базовый SHA / ветка / PR:
- План:
- Файлы:
- Запреты и риски для данных:
- Предварительная резервная копия (где, без приватной ссылки):
- Проверка до исправления:

### YYYY-MM-DD — RUN-NNN — ПРОВЕРКА
- Код: перечень изменённых файлов и почему
- Автоматические тесты (команда, commit, run ID, PASS/FAIL):
- Ручные проверки (что и кем подтверждено):
- Побочные эффекты, нерешённые вопросы:
- Откат:

### YYYY-MM-DD — RUN-NNN — ЗАВЕРШИЛ / ОЖИДАЕТ РУЧНОЙ ПРОВЕРКИ
- Merge commit и PR:
- Что реально работает:
- Что осталось проверить на iPhone / Google Drive:
- Следующий безопасный шаг:
```

Не вставлять в GitHub пользовательские стихи, песни, тексты журналов, идентифицирующие данные клиентов, OAuth-токены и приватные экспортные файлы. Не писать «ЗАВЕРШИЛ» только на основании компиляции: нужен PASS тестов, слияние и явное уточнение границ ручной проверки.
