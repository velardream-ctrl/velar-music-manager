# RUN-167 — Непрерывный эфир и ручное переключение треков
17 ноября 2026 года. Владелец запросил автоматическое переключение песен и обязательное сохранение кнопки «Следующая песня» для ручного пропуска неподходящего трека.

## Архитектура
- YouTube IFrame Player API: cuePlaylist для начального блока до 100 валидированных видео; внутренний nextVideo по ручному нажатию; обработка завершения последней песни блока для loadPlaylist следующей порции. До 300 песен из уже опубликованного каталога, первичная рандомизация и новая рандомизация между циклами.
- Кнопка сохранена в раскрытом и мини-плеере; при сворачивании сам iframe не уничтожается. Старт только после действия пользователя; после блокировки autoplay браузер может требовать нажатия ▶ в YouTube.
- Неактивный/недоступный YouTube API: нативный параметр playlist для первых 100 и ручное переключение без гарантии обхода всей длинной очереди.
- Spotify/Apple Music: ручное переключение между официальными iframe по клику, не ложно декларировать автоопределение конца трека. Для официальных плейлистов внутренний сервис сам определяет порядок и продолжение.
- Не менять палитру, режимы золотого свечения RUN-166, перемещение и размеры видимого iframe в свернутом режиме. Устаревший iPad использует отдельный совместимый видео-модал.
