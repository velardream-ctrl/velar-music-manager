# RUN-064 — справочник артистов и назначение песен галочками

Дата: 11.11.2026
Статус: реализация в GitHub, требует проверки после публикации.

## Пользовательский порядок

1. Войди в https://velardream.com/studio/ через Google.
2. Перейди в «Главная страница» → «Артисты».
3. В списке «Добавить артиста из каталога» выбери DJ Velar, Илья Дмитриев, Crazy Bobr или иное имя из закрытого каталога; нажми «Добавить артиста».
4. Карточка артиста создастся скрытой для посетителей. Публичное имя можно изменить без переименования релизов у дистрибьютора.
5. Нажми «Назначить песни». Найди песни по названию/исходному исполнителю, отметь галочками нужные. Можно отметить или снять все найденные песни, даже если одновременно показываются только первые 80.
6. Нажми отдельную кнопку «Сохранить привязки песен». При переносе песни от другого артиста будет предупреждение.
7. Затем отдельно сохрани черновик карточки и, когда данные проверены, используй кнопку «Опубликовать» для страницы. Назначение песен не публикует их названия автоматически.

## Устройство и безопасность

В базе исходного каталога vmm_catalog НЕ изменяются artist, UPC, ISRC, ссылки и ID. Для DJ Velar, Илья Дмитриев и Crazy Bobr используются стабильные ключи velar, ilya-dmitriev, crazy-bobr. Оригинальные имена служат автоматически вычисляемой подсказкой. Индивидуальные исключения, например перенос песни с исходным artist=Velar к Crazy Bobr, хранятся отдельно в закрытом документе vmm_links/artist_track_assignments_v1 (trackId → artistId).

Это существующая админская коллекция с правилами studioAdmin. Новые Firestore Rules для самих связей песен не требуются. Документ хранит только IDs, ревизию и время изменения; не копирует тексты песен, аудио, приватные URL. Служебный документ исключён из очереди предложений музыкальных ссылок. Сохранение защищено транзакцией и номером ревизии от перезаписи с другого устройства.

Снятие галочки возвращает исходное распределение или оставляет песню без назначенного артиста (для осознанно снятой стандартной связи). Это обратимый, приватный слой поверх существующего каталога.

## Пока отдельно

- Внешний дистрибьютор RouteNote и уже опубликованные кредиты Velar не изменяются. Их исправление — отдельная задача.
- Отдельная коллекция vmm_artists пока не создана: версия RUN-064 выбирает названия из текущего каталога и согласованных трёх профилей.
- Назначение песни не делает её общедоступной. На landing page выводятся только явно опубликованные карточки и заранее выбранные публичные релизы.
- Для сохранения и публикации самой landing CMS всё ещё требуется применение и проверка правил RUN-062: владелец сообщил о вставке правил, но не подтвердил нажатие Publish.
- После выхода RUN-064 проверить реальную работу в Safari, Firefox и Chrome на компьютере и телефоне.

## Восстановление

Назначения можно отменить вручную галочками. Прежде чем проводить массовую очистку служебного документа, сначала сделать его резервную копию. Остальные документы коллекции vmm_links не удалять.
