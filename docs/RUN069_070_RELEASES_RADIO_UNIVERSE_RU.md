# RUN-069 / RUN-070 — Релизы, VELAR RADIO, плейлисты, подписки, музыкальная вселенная

Дата: 2026-11-11. Статус: код в отдельной ветке, готовится к слиянию. Версия сайта и PWA обновлена.

## Запрос владельца
Главная — аккуратная музыкальная витрина: сначала избранный релиз и видеопремьера, ниже карточки с фильтрами; отдельные плейлисты и подписки с предоставленной ссылкой https://open.spotify.com/playlist/11Vdx5lXmtfMiXh63YhIwh; постоянная компактная кнопка VELAR RADIO с возможностью слушать музыку. Новая интерактивная двух-/трёхмерная визуализация, «как сайт будущего», но совместимая со старым Samsung и Safari 12. Минимизировать расход бесплатных квот и исключить риск накрутки Spotify/YouTube.

## Реализация
- Публичный `#releases`: заголовок сверху; две крупные карточки избранного релиза и клипа по выбору админа; фильтры «Все/Синглы/Альбомы/Видеоклипы»; стартовый пакет 6, далее «Показать ещё». Обложки квадратные, клипы 16:9; есть fallback через CSS `::before` для Safari 12. При отсутствии обложки — локальный геометрический placeholder, при клипе — YouTube thumbnail с `loading=lazy`. Никаких скачиваний из частного каталога.
- Studio → «Главная страница → Музыка и релизы»: можно вручную добавить из закрытого каталога песню с проверенной прямой ссылкой Spotify/YouTube, указать тип/главную витрину/официальный embed, загрузить и сжать свою квадратную обложку на устройстве до 90 КБ, сохранить черновик и отдельно опубликовать. Новые карточки из каталога создаются скрытыми (visible=false), пока админ их не проверит.
- Studio → «Плейлисты и подписки»: до 8 прямых Spotify/YouTube плейлистов и до 6 проверенных Spotify/YouTube/Telegram страниц подписки; смена площадки, видимости, порядок через список, радио (площадка, URL, название, включение). Основной Spotify-плейлист и профиль DJ Velar проверены по предоставленному владельцем Google Sheets «Ссылки артиста · автопост». Адреса в публичном JSON нормализуются без отслеживающих параметров.
- `VELAR RADIO`: кнопка закреплена внизу справа, плеер создаётся **только после нажатия «Открыть плейлист»**. Никакого автоматического, скрытого, muted, бесконечно циклического или бот-воспроизведения. Плеер официальный Spotify или YouTube. Встроенный каталог только по настройке плейлиста, а не автоматически по частным фонограммам. Закрытие плеера удаляет iframe и останавливает поток.
- `VELARDREAM Universe`: дополнительный раскрываемый интерактивный раздел с 6 «созвездиями» артистов, релизов, клипов, плейлистов, жанров и радио. В настольном браузере с указателем — лёгкий CSS-параллакс/перспектива только во время движения мыши; на телефоне — двухколоночная сетка, без наклонов и наложения кнопок; при `prefers-reduced-motion: reduce` — статичное представление. Данные берутся исключительно из **того же одного** разрешённого опубликованного документа `vmm_public_pages/landing`, дополнительных чтений Firestore нет.
- Запрещённые ссылки (`javascript:`, Google Drive, частный Storage, произвольный сайт, некорректная площадка) не проходят whitelist схемы; Firestore Rules **не меняются**. Доступ Studio к частному каталогу возможен только после подтверждения Google admin. Только проверенные публичные поля уходят в опубликованный документ.

## Лимиты и безопасность
- GitHub Pages: мягкий ориентир около 100 ГБ/месяц трафика. Не путать с 20 000 URL Fetch/сутки в Apps Script.
- Firestore Spark: 50 000 document reads/сутки и 20 000 document writes/сутки (актуальные точные условия проверять отдельно на официальной странице). На публичной странице используется только существующий listener одного документа; ни клипы, ни Universe, ни радио не открывают дополнительный listener.
- Spotify embeds/YouTube embeds полностью сторонние. До клика iframe не создаются; клипы не подгружаются как видео, thumbnails имеют lazy load. На активной странице по кнопкам при смене источника предыдущие созданные iframe удаляются; нет фоновых `setInterval`, `requestAnimationFrame`, WebGL, видео-фонов или запросов к внешним рекомендациям.
- Собственные воспроизведения для искусственного увеличения Spotify/YouTube статистики и обхода правил платформ запрещены. Для легальных роялти учитываются правила платформ; превью может не считаться прослушиванием. Никаких обещаний, что каждое включение на сайте приносит деньги.
- Сам сайт не содержит MP3/FLAC; оригинальные аудио, тексты, catalog, UPC/ISRC и Drive остаются неизменными.

## Ручная приёмка после публикации
1. Открыть https://velardream.com/?v=70 на Samsung/Firefox/Safari 12/iPhone. Под заголовком релизов проверить правильные пропорции обложек, фильтры, «Показать ещё» и отсутствие двойного воспроизведения.
2. Проверить отдельный раздел «Плейлисты и подписки» — предоставленный Spotify-плейлист и подтверждённый профиль артиста.
3. На RADIO проверить, что до клика **нет** звука и запросов к внешнему player iframe; по клику плеер открывается; закрытие прекращает воспроизведение. Радио не обещает бесконечное воспроизведение вне правил Spotify/YouTube.
4. «Исследовать вселенную» → выделить все 6 созвездий мышью/пальцем/клавиатурой; на iPad нет наложения, настройка reduced-motion отключает наклоны; при закрытии не остаётся фонового цикла.
5. В Studio проверить изолированное сохранение черновика и отдельную публикацию, работу ссылок Spotify/YouTube, сжатие обложки и отсутствие доступа чужих аккаунтов.
6. Проверить фактическую квоту в Firebase Console Usage и трафик через GitHub Pages; реальную нагрузку нельзя гарантировать одним unit test.
