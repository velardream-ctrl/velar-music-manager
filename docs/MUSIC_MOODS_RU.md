# Музыка по настроению
Шесть утверждённых карточек (солнце, дождь, ноты, сердце, луна, пламя) над существующими тематическими планетами и тегами. Studio → Главная страница → Темы песен → Музыка по настроению. Включение, порядок, названия, видимость и связи с опубликованными темами. Первоначальные связи являются редакционным приближением, не анализом аудио; корректируются владельцем. Помощник получает быстрые кнопки и распознаёт общие запросы. Прямые официальные плееры, без автозапуска. Нет новых чтений базы или изменений правил.
