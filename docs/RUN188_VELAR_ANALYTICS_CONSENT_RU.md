# RUN-188 — добровольное согласие на аналитику через DJ Velar
Дата: 17.11.2026.

## Запрос владельца
Объяснять сбор статистики с помощью существующего чат-помощника DJ Velar при первом открытии чата. Дать равнозначные варианты «Разрешить аналитику» и «Отказаться». После ответа не напоминать. Не использовать IP для идентификации посетителя.

## Реализация
- GA4 Web Measurement ID G-ZD640V3VQ1 применяется только после включения владельцем в Studio → Главная страница → Статистика посещений и отдельного разрешения посетителя.
- При включённом помощнике не выводится отдельная всплывающая панель аналитики: DJ Velar при первом открытии чата в данном сеансе рассказывает, какие данные собираются и для чего. После приветствия предлагает две равнозначные кнопки. Понимает явный текст «отказываюсь» или «согласен» при открытом предложении.
- На данном устройстве выбор хранится в localStorage ('yes'/'no'), не по IP, не по email, без регистрации. Отказ действует и на последующих визитах, пока посетитель сам не изменит выбор. Если выбор не сделан — не чаще одного приглашения за сеанс чата. Если помощник отключён, остаётся стандартный независимый баннер с обеими кнопками.
- Ссылка «Настройки статистики» внизу сайта даёт посетителю возможность отозвать разрешение. Отказ не препятствует пользованию музыкой. При отзыве дальнейшие события запрещаются, предпринята очистка GA cookies на домене.
- До согласия не загружается скрипт gtag.js, не посылаются события, GA4 не используется. После согласия отправляются page_view и события открытия официальных плееров/радио из RUN-186. Клики ≠ фактические прослушивания Spotify/Apple Music.
- Публичные Firestore Rules, защищённый музыкальный каталог, радио и стили кристалла не менялись. В админке пока есть настройка сбора, но нет реальных агрегированных отчётов; публичный счётчик тоже ещё не работает.

## Дальнейшие действия владельца
1. После попадания кода на сайт войти в Studio → Главная страница → Статистика посещений.
2. Включить «GA4 с добровольным согласием через помощника Velar». Сохранить черновик, затем опубликовать.
3. Проверить в новом приватном окне на iPhone: первое открытие чата → две кнопки. Отказ → Google Analytics не загружается, на повторном открытии помощник не спрашивает. На другом устройстве выбор независим.
4. Разрешить на тестовом устройстве и проверить Google Analytics → В реальном времени. Не проверять корректность статистики по одному только просмотру страницы без согласия.
5. В дальнейшем дополнить политику конфиденциальности контактами оператора, назначением и сроками хранения по настройкам GA4. Не путать переключатель будущего публичного счётчика с работоспособной отчётностью.

## Передача/восстановление
Исходники analytics-public.js, velar-assistant.js, landing-public.js, studio/firebase-config.js, настройки landing и тесты должны попадать в резервные копии и журнал восстановления.
