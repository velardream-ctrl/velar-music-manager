# RUN-168 — шкала золотого свечения VELAR RADIO 1–100%
Дата: 17 ноября 2026 года. Владелец попросил изменить настройку минимального размера свечения с 50% на 1% и позволить пошаговую настройку до 100%.

## Что изменено
- Studio → Главная страница → VELAR RADIO → «Размер светового ореола»: минимум 1, максимум 100, шаг 1 процент.
- В опубликованной схеме radio.visual.spread допустимы любые целые 1–100. Некорректные или отсутствующие значения получают новый безопасный размер 20%. Ранее явно сохранённые 50%, 75%, 100% продолжают действовать без изменения.
- При диаметре круга 68 пикселей: 1% — 0,68 пикселя наружу, 50% — 34 пикселя, 100% — 68 пикселей. Расчёт точный и для промежуточных значений. Сохраняется визуальное обновление без пересоздания работающего официального iframe.
- Сердцебиение, послесвечение, остальные режимы, яркость 1–5, ручное управление песнями, автопереход YouTube, drag и настройка reduced-motion не меняются.
- Обновлены версии JS и Service Worker для Safari/iPad и Studio; актуализированы регрессионные проверки tests/test-radio-visual.mjs, tests/test-release-radio.mjs, tests/test-landing-admin.mjs.

## Уточнение владельца перед публикацией
17.11.2026 — первоначально предполагался прежний default 50%. Владелец исправил решение: **по умолчанию 20%**. Для 68px значка это 13,6px с каждой стороны; диапазон 1–100% с шагом 1% не меняется. Существующие явно выбранные 50% не переписываются автоматически, чтобы не потерять настройки пользователя. Чтобы сделать 20% на уже опубликованном радио, необходимо сохранить и опубликовать выбранные 20% в Studio.
