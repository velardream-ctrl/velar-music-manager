# VELARDREAM RECORDS — структура первой страницы

Статус: первая публично видимая **демонстрационная витрина**, без личных данных и без выдуманных релизов. Домашняя страница используется как визуальная заставка и одновременно как полноценная семантическая страница.

## Визуальная идея
- Синий звёздный фон, молочно-золотые акценты и **оригинальный предоставленный владельцем логотип VELARDREAM RECORDS** (не генерация новой графики).
- Лёгкая верхняя навигация; главный логотип как центральный визуальный объект; внизу hero — краткое текстовое представление и 2 кнопки.
- Ниже — спокойные секции с понятными надписями, пока без вымышленных дискографий.

## Блоки
1. **Hero / Главная заставка**: изображение логотипа, текстовый H1, краткий слоган, ссылки к артистам и релизам.
2. **Артисты**: будущие индивидуальные профили с собственной стилистикой, аватарами, дискографией, аудио/видео embed.
3. **Релизы**: синглы, альбомы, клипы, платформы; не хранить собственное аудио в Firestore.
4. **Жанры**: набор тегов как направления, отдельно от подборок/плейлистов.
5. **О проекте**: кто объединяет исполнителей, история и дальнейшие возможности.
6. **Личный кабинет**: ссылка на отдельный /app/, пока безопасная заглушка; в будущем защищённая зона Firebase с собственными правилами и офлайн-синхронизацией.

## SEO
- Title, description, HTML H1/H2, alt изображения, обычные href-ссылки к разделам, canonical адрес и Open Graph. Дизайн с большим логотипом не обязан быть SEO-пустой заставкой.
- До согласованного публичного запуска **сохранён noindex**. Его нельзя убирать, пока приватная авторизация и контент не готовы. Сам noindex не делает страницу закрытой от прямых посетителей.
- После публикации настоящих профилей артистов — расширять страницу, добавить постоянные человекочитаемые URL и sitemap, настроить Search Console. Не обещать позиции в поиске заранее.

## Совместимость
- Статический HTML/CSS и JS ES5 без SPA-фреймворка, поддержка мобильных экранов; JS не требуется для меню и основного содержимого.
- Service Worker кэширует только публичные файлы, включая логотип; версия cache обновлена для доставки новой главной. Это **не** офлайн-редактор песен (его реализуем отдельно).
- Не использовать внешние шрифты или обложки, чтобы сохранить скорость и бесплатные лимиты.
