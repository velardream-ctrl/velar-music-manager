Классический и компактный виды используют единый опубликованный каталог. В Studio на вкладке «Оформление главной» задаётся общий вид. После публикации выбранный вид применяется для всех посетителей.

В разделе «Темы песен» родитель объединяет подборки. Поле «Самостоятельная тема» снимает связь с группой и сохраняет песни. Темы без песен и без наполненных подтем скрыты. Подтемы появляются после выбора родителя. Отдельные алиасы вводятся через запятую для поиска помощником.

Ползунок загрузки управляет обложками и построением разделов. Публичный каталог по-прежнему читается одним документом. Прямой переход к песне открывает нужный раздел сразу.
