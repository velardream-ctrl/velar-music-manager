# RUN-201 — Universal Auto Carousel + Velar Smart Navigation

Рабочая ветка `feature/run201-smart-navigation-carousel`, исходный коммит `8df2414a3ef347eb7a873d7b2ab03935aa33d9bf`. Домен подтверждён CNAME, описанием GitHub Pages и побайтовым сравнением опубликованного index.html с копией исходного коммита.

Studio → Главная страница → Оформление главной. Владелец выбирает список, карусель или автокарусель для подборок. В раскрывающемся блоке каждого артиста доступны отдельные настройки для главной и профиля. Скорость 1–100%, направление и поведение на границе хранятся в черновике вместе с оформлением. Существующие документы получают прежний вид до выбора владельца.

Поиск в smart-navigation.js использует видимые записи того же опубликованного снимка, который читает главная страница. Результат содержит вид подборки, ключ, проверенную ссылку и намерение воспроизвести. Чат обрабатывает музыкальные команды локально до обращения к Cloudflare. При неоднозначности посетитель выбирает трек. Статистика открытия принадлежит обработчику плеера. Внешний плеер управляет воспроизведением. YouTube получает параметр autoplay только при запросе «Включи». Пользователь может нажать Play внутри плеера.

Компонент public-song-ui.js обрабатывает поиск на нужной странице списка, центрирование и остановку движения. Удалённый переход в длинной карусели создаёт окно карточек вокруг результата. Изменения охватывают публичные рендереры альбомов, тем, языков, жанров и артистов, помощник, схему оформления, редактор Studio, стили, оболочку офлайн-кеша и проверки. Точный перечень файлов доступен в diff ветки.

Исходный git bundle проверен git bundle verify и отдельным восстановлением checkout. Контрольный сценарий после слияния: выполнить git revert -m 1 <merge-SHA> при слиянии merge-коммитом или git revert <squash-SHA> при squash, запустить npm test, опубликовать через GitHub Pages и сверить файлы на домене. До отката к старому коду вернуть стандартные режимы в Studio, если автокарусель уже была опубликована в настройках: прежняя схема не принимает значение auto. Резервная копия кода не содержит Firestore, Firebase Authentication или D1.
