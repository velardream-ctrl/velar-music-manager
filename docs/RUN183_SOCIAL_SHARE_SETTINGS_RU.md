# RUN-183 — социальные сети и кнопка «Поделиться» (17.11.2026)

Статус: реализовано в отдельной ветке, до проверки CI/слияния не считать опубликованным.

## Причина
PWA на iPhone/iPad скрывает адресную строку: посетителю нужна доступная кнопка передачи URL сайта. Владелец запросил общую управляемую строку внизу главной и официальные ссылки для каждого артиста без автопоказа.

## Реализация
- Studio → Главная страница → Оформление главной → **Социальные сети и «Поделиться»**. Два независимых переключателя: показать нижнюю панель и показать кнопку системного sharing. По умолчанию оба выключены; нет внезапного изменения публичного интерфейса.
- До 12 HTTPS ссылок на официальные профили: Facebook, ВКонтакте, Instagram, TikTok, LinkedIn, YouTube, Telegram, Spotify, Apple Music и другие поддерживаемые платформы. Каждая имеет отдельную видимость, добавление и удаление.
- Прежние ссылки отдельных артистов сохранены; LinkedIn добавлен в существующую Studio → Артисты → Персональная страница → Официальные площадки.
- Посетитель видит только включённые опубликованные ссылки. Кнопка «Поделиться» в будущем использует Web Share API и резервное копирование адреса/ручную подсказку, без сторонних скриптов. Вся панель скрыта до ручного включения.
- Отдельная кнопка «Поделиться страницей» в публичных профилях артистов уже существовала (RUN-115) и не удалена.
- Данные проходят существующую нормализацию, отдельные Firestore draft/published и проверку конфликтов. Новых коллекций Firebase и правил Firestore нет.
- Существующие плееры, радио, анимации и lazy-loading не менялись.

## Включение
1. В Studio выбрать «Главная страница» → «Оформление главной».
2. Внизу найти социальные сети, добавить ссылки и поставить для нужных «Показывать эту ссылку».
3. Когда всё готово, включить «Показывать нижнюю панель» и при желании «Поделиться сайтом».
4. Сохранить черновик, затем отдельно опубликовать. Проверить в PWA iPhone, старом iPad/Safari, браузере.
5. В «Артисты» при необходимости добавить индивидуальные ссылки в уже существующую персональную секцию.

## Ограничения
- Это ссылки и встроенный sharing, не автоматическое размещение постов в соцсетях, не OAuth/API-интеграция.
- Ссылки должны быть настоящими официальными HTTPS-профилями; ссылки на отдельные треки в профилях отклоняются.
- Никакой социальный профиль не придуман и не подключён автоматически.
- После публикации потребуется отдельная визуальная ручная проверка владельцем.
- При существенных будущих изменениях дополнять этот журнал и инструкции восстановления.
