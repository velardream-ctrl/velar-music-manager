# RUN-171 — восстановление iPhone-прокрутки кристалла, радио и помощника
Дата: 17.11.2026.

## Проблема и эталон
На iPhone при прокрутке сверху вниз пропадает кристалл, остаётся пустая область, плавающие радио и помощник визуально уходят наверх. При прокрутке снизу вверх кристалл появляется. Владелец уточнил, что до исправления логотипа радио старого iPad (RUN-170) на iPhone всё было нормально. PNG на старом iPad теперь отображается и не должен быть отменён.

## Исследование
В RUN-170 изменены ссылки на ассеты и кэш, но логика скролла осталась старой. Нельзя считать PNG доказанной причиной. В CSS есть мобильная sticky сцена высотой 100vh, глава 158vh и body overflow-x clipping. Их сочетание потенциально приводит к неверным композитным слоям Safari и пустым областям при прокрутке. Прямой аппаратной проверки нет.

## Изменения
- Только iPhone/iPod по user-agent: класс html.ios-scroll-stable.
- Для iPhone сцена кристалла теперь находится в обычном потоке без sticky, глава без 158vh spacer, сцена min-height 650px; сохраняется скролл-зависимая трансформация кристалла, колец и фаз.
- Формула прогресса короткой сцены исправляется только на iPhone; iPad и desktop не меняются.
- На iPhone fixed радио/помощник получают собственный GPU compositing layer, body overflow-x visible, reveal-заголовки не исчезают при пропущенном observer callback.
- Без изменений: PNG эмблема старого iPad, YouTube auto-next, Spotify/Apple Music, draggable orb, стиль и настройки свечения, права и Firebase.
- style.css?v=79, living-art.js?v=3, SW v89.

## Проверки
Автотесты для iPhone/iPad/desktop, новых параметров и полной CI; результат подтвердить после запуска.
