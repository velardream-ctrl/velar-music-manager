# RUN-071 / RUN-072 — Одобренный кристалл, управляемая вселенная и языковые миры

Дата: 2026-11-11. Сайт VELARDREAM RECORDS. Контент одобрен владельцем: использовать только оригинальный кристалл из логотипа, без сферы, волны, текста и перерисованной эмблемы.

## Художественная основа RUN-071
- Центральное изображение **только** `assets/velardream-symbol.svg`, тот же исходный фирменный кристалл, который используется в верхнем/нижнем логотипе; исходная шапка сайта с основным логотипом остаётся без изменений.
- `living-art.js` + CSS: сцена истории при прокрутке между первым экраном и артистами. Никаких фоновых HTTP-запросов, видео, аудио или WebGL. Расчёты только в момент видимости и только при достаточной поддержке браузера; при reduced-motion/Data Saver или старых браузерах — статичная версия.

## RUN-072 — изменение орбитальных меню из Studio
- Содержимое `genres.universe` в том же уже опубликованном публичном документе `vmm_public_pages/landing` (не создаём новые коллекции/слушатели/платные ресурсы).
- Поля редактора: заголовок и интро, до 12 созвездий с `id` (уникальная латиница и дефис), названием, коротким описанием, целью перехода и видимостью. Созвездия разрешено добавлять, переименовывать, упорядочивать, скрывать и удалять. Цели разрешены только внутри сайта: `artists,releases,playlists,genres,languages,about,radio`. Любые приватные адреса/JS URL отклоняются схемой.
- Внутри `universe.js` визуальный цикл статичен: нет setInterval, таймеров, фонового поворота. Посетитель может поворачивать орбиту вручную стрелками; выбор отдельной кнопки подсвечивает золотую связь с кристаллом. Более восьми видимых созвездий отображаются упорядоченной сеткой, чтобы кнопки не накладывались.

## RUN-072 — Миры языков и песни
- Список подтверждён по обсуждениям пользователя от 13.10.2026: **русский, английский, итальянский, французский, немецкий, финский, урду, венгерский, испанский, нидерландский, турецкий**. Два *авторских вымышленных* мира: **бобриный язык Crazy Bobr** и **инопланетный экспериментальный язык**.
- Китайский не добавлен автоматически: пока подтверждены только элементы, а не полноценная песня. Новые языки можно добавлять в админке.
- `genres.languages.entries`: до 20 записей, у каждой код, название, `fictional`, `visible`, список из максимум 300 утверждённых песен `{title,artist,provider,url}`. Публичные ссылки на треки — строго верифицированные прямые Spotify/YouTube из `VMM_LANDING_SCHEMA.songUrl`; приватные Firestore документы, аудиофайлы и тексты не копируются. Глобальный лимит публичного документа сохраняется 780000 символов (вместо расширения квот).
- В Studio → «Языки песен»: добавить/удалить/переименовать язык; пометить как вымышленный, скрыть/показать; открыть любую категорию и вручную назначить песни поиском по закрытому каталогу, Spotify или YouTube, исключить неверную привязку. Для добавления нескольких песен подряд редактор сохраняет позицию поиска и не перерисовывает всю страницу после каждого нажатия.
- Язык не угадывается по названию песни; **все 13 языков по умолчанию не имеют назначенных песен**. До ручного выбора каталогом пользователю показывается честная надпись, а не пустой или фиктивный Play.
- `languages-public.js` не читает Firestore; получает только уже отфильтрованные и нормализованные данные из главной страницы. Отдельный визуальный язык представлен языковыми созвездиями вокруг **того же исходного SVG-кристалла**. На старых планшетах — 2–3 колонки без наложения. Выбор языка открывает до 14 песен и кнопку «Показать ещё»; официальный плеер Spotify/YouTube создаётся по отдельному клику. Закрытие удаляет iframe; другие активные iframe закрываются. Никаких скрытых автопрослушиваний, циклов и обходов правил площадок.

## Данные и публикация
- Ключи верхнего уровня `hero,artists,releases,genres,about` и `schemaVersion=1` сохраняются. **Firestore rules не меняются**, поскольку новые поля вложены в `genres`. Приватный `vmm_catalog` доступен редактору только после стандартной проверки прав Google admin.
- Сохранение черновика не публикует ничего. Только команда «Опубликовать» записывает новый нормализованный набор публичных полей; удаление созвездия/языка остаётся обратимым через сохранённый черновик до публикации. Для отката — предыдущий опубликованный контент, версии документов и Git.
- Публичная страница использует тот же один Firestore listener, новые разделы не открывают повторных чтений. Встроенные плееры и изображения по-прежнему загружаются по требованию. Версии CSS, JS и PWA-инструментов обновлены для Samsung и iPhone.

## Проверка после публикации
1. На Samsung и iPhone открыть `https://velardream.com/?v=72`; проверить подлинный кристалл в статичной сцене и центре движущихся вручную созвездий, разные размеры экрана, отсутствие голубых emoji.
2. Посмотреть раздел «Музыка на языках Вселенной»; без указанных песен он должен показывать названия и корректные пустые состояния.
3. В Studio → «Созвездия» проверить новое меню, изменение порядка/названия, скрытие, удаление, режим сетки, сохранение и отдельную публикацию.
4. В Studio → «Языки песен» выбрать один язык, найти и назначить проверенную песню, сохранить черновик и опубликовать. На публичной странице проверить правильную фильтрацию, кнопку Play и закрытие iframe.
5. Убедиться, что `VELAR RADIO` не начинает скрытое воспроизведение, правила доступа не изменились, а лимиты в Firebase Console остаются ожидаемыми.
