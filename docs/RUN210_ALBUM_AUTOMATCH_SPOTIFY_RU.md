# RUN-210 — Альбомы Spotify: список композиций и сопоставление с каталогом

Дата: 22.11.2026

## Почему показывалось «0 песен»

Редактор сохранял `albums.entries[].mediaUrl` (адрес официального альбома Spotify) отдельно от `albums.entries[].tracks`. На публичной странице ранее показывались только элементы `tracks`, назначенные вручную в Studio. Чтения состава альбома из Spotify не было. Из-за этого официальный альбом «Игристая Весна» с действительной ссылкой, но `tracks:[]`, отображался без песен.

## Исправление публичного сайта

- При раскрытии **официального** альбома с корректным адресом `https://open.spotify.com/album/{22-char-id}` появляется встроенный официальный Spotify Album player. Он отображает песни, принадлежащие альбому в Spotify.
- Запрос к Spotify НЕ выполняется до нажатия «Показать песни». Закрытие удаляет iframe.
- Если в собственном каталоге есть назначенные песни, они остаются в нативном списке с площадками Spotify/YouTube/Apple Music, а официальный Spotify album player появляется дополнительно.
- При нуле собственных назначений вместо ложного «0 песен» написано «Полный список композиций — в Spotify».
- Авторские коллекции из синглов без официального Spotify album URL ведут себя по-прежнему.

## Исправление редактора

- Для вкладки **Studio → Главная страница → Альбомы** появился блок «Автосопоставление песен альбома».
- Из Spotify можно скопировать список названий (по одному на строку): `Название — Исполнитель`, только `Название` при известном исполнителе или прямую ссылку `https://open.spotify.com/track/{id}`.
- Нажатие **Найти совпадения в каталоге** ищет только точные совпадения по названию и исполнителю либо Spotify Track ID. Неоднозначные и отсутствующие варианты помечаются, но не прикрепляются.
- Нажатие **Добавить найденные песни** добавляет только явно проверенные совпадения, без дубликатов. Данные проходят существующий `API.normalize` до записи в локальный черновик. Схема Firestore, доступ к закрытому каталогу и публикация не меняются.
- Имена, ссылки и описания приватного каталога не передаются внешнему сервису. Сопоставление происходит в браузере вошедшего владельца.
- Максимум 60 строк за попытку и 60 песен на альбом. Для песен с несколькими площадками берутся существующие проверенные ссылки.
- Сначала **Сохранить черновик**, дождаться облачной синхронизации, затем **Опубликовать**.

## Что пока невозможно без дополнительного подключения

Прямой автоматический импорт списка треков только по одной Spotify album URL в собственный каталог требует разрешённого Spotify Web API с OAuth (и действующих ограничений Spotify Developer). В этом обновлении Spotify Web API не подключён, ключи/токены не создавались и не сохранялись в GitHub, браузере или Firebase. Сам официальный Spotify Embed умеет отображать список треков посетителям без нашего чтения метаданных. В Studio для точного сопоставления требуется вставить названия/ссылки из Spotify.

- `npm test` — общие проверки проекта.
- На iPhone проверить отсутствие переполнений и возможность вставлять несколько строк.
- После публикации проверить официальный альбом «Игристая Весна» на живом сайте. Наличие списка Spotify внутри iframe не означает, что песни автоматически записались в частную базу.
