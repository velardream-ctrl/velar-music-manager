# RUN-192 — DJ VELAR AI / защищённая лаборатория Cloudflare
Дата: 17.11.2026

## Цель
Владелец хочет бесплатную (в рамках лимита) модель с открытыми весами, помогающую существующему DJ Velar отвечать на нестандартные вопросы, не замедляя публичный сайт, не ломая локальные команды и не занимая его GitHub крупными файлами.

## Решение первого этапа (owner-only)
- Cloudflare Workers AI на Free. Пробная модель `@cf/meta/llama-3.1-8b-instruct-fp8` (не загружать в репозиторий). По официальным тарифам Cloudflare Workers AI Free имеет 10,000 Neurons / сутки; после превышения без перехода на Paid вызовы отклоняются. Работоспособность конкретной модели, квоты и локализации проверить в Cloudflare после развёртывания.
- `cloudflare/dj-velar-owner-lab.js`: отдельный Worker с AI binding по имени `AI` и Secret `VELAR_OWNER_TEST_TOKEN`, HTTPS, разрешённый Origin `https://velardream.com`, endpoint `POST /v1/owner-test`; строго запрещает публичные запросы без длинного токена. `/health` показывает readiness без каких-либо секретов. Сервер не содержит ключей Firebase/Firestore и не исполняет команды сайта.
- `studio/ai-lab.js`: тестовая форма в Studio → Главная страница → Помощник VELAR. Поля: HTTPS URL Worker, секрет владельца, выбор ru/fi/en, тестовый вопрос; результат только текстом, без HTML/URL/скриптов. **Секрет НЕ сохраняется в Firebase, public landing, GitHub или localStorage**, по выходу из вкладки потребуется ввод снова. Текст вопроса отправляется в Cloudflare только по явному нажатию владельца.
- Исходный `velar-assistant.js`, правила, FAQ, радио, кристалл, плееры и Firestore Rules не изменены. Публичный `index.html` не подключает ИИ-скриптов и не обращается к Cloudflare. Публичная интеграция ПОКА ЗАПРЕЩЕНА, тесты и сравнение с базой правил — обязательны. В случае выключенного/отсутствующего Worker ничего не ломается.

## Пошаговое создание в браузере без установки программ
1. Открыть https://dash.cloudflare.com/ → создать бесплатную учётную запись или войти. Не включать Workers Paid/добавлять карту ради теста.
2. Перейти в Compute (Workers) / Workers & Pages → Create → Worker → Start with Hello World / Edit code (названия могут отличаться). Назвать `dj-velar-private-lab`. Имя Worker должно быть уникальным.
3. Скопировать **полный** код `cloudflare/dj-velar-owner-lab.js` из GitHub (ветка RUN-192/после слияния main) в редактор Worker вместо шаблона. Save and Deploy.
4. Settings / Bindings → Add → Workers AI → имя binding **AI**. Save / Deploy.
5. Settings / Variables and Secrets → Add Secret, name **VELAR_OWNER_TEST_TOKEN**. Value = уникальная случайная строка НЕ КОРОЧЕ 32 символов, сгенерированная в менеджере паролей. Сохранить её в менеджере паролей, **не отправлять в ChatGPT/скриншот/код/базу/письмо**.
6. Открыть `https://<worker-name>.<account>.workers.dev/health` — ожидается `status: private-lab`, `ready: true`, `publicEnabled: false`. Адрес своего Worker не секрет.
7. В Studio → Главная страница → Помощник VELAR → Лаборатория DJ Velar AI, вставить URL `https://...workers.dev/v1/owner-test`, секрет из менеджера паролей, вопрос. Нажать «Проверить ответ модели». Проверить качество русского/финского/английского и неупоминание вымышленных треков.
8. В Cloudflare Workers AI Dashboard смотреть использование Neurons. При ошибке/квоте ответы не появляются: существующий DJ Velar остаётся локальным.

## Дальнейшая работа после тестового развёртывания
- Подключить маршрутизатор: локальные команды, правила владельца и известный каталог всегда идут первыми, ИИ — только для незнакомых формулировок. Исключить раскрытие приватного каталога, редактирование сайта без авторизации и самовольный запуск музыки.
- Для публичного доступа необходима **отдельная серверная защита от злоупотреблений**: rate limit/квоты, бюджет, проверка реального запроса (например Turnstile или иная подтверждаемая защита), политика сообщений и согласие на передачу вопросов внешнему процессору. Секрет владельца нельзя использовать в браузере посетителя.
- Для рекомендаций предоставить ИИ только минимальный подтверждённый список опубликованных треков и их категорий (без закрытого каталога), с проверенным songId и whitelist команд.
- Динамическая память = обновляемая база и одобренные владельцем ответы; модель не переобучается сама в ходе чата.
