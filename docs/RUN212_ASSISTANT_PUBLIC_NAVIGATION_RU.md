# RUN-212 — Навигация DJ Velar по публичному сайту

Дата: 22.11.2026.

## Возможности

- Новый модуль `site-navigation-catalog.js` (совместимый с iOS12 Safari) обнаруживает публичные ссылки из `.site-nav` и видимые секции `main section[id]` с заголовками. Новые разделы становятся доступными по запросам «где», «открой», «покажи раздел» без ручного изменения словаря.
- При «Сотрудничество» DJ Velar предлагает открыть категорию форума (если опубликована и включена) либо обратиться лично через «Контакты». При просьбе написать сообщение или заказать песню открывает `/contacts/`.
- Категории форума запрашиваются один раз из публичной коллекции Firestore `velar_forum_sections` (GET, pageSize=100, без credentials). В навигацию попадают только включённые и не удалённые категории с допустимыми названиями и id. Если чтение недоступно, предлагается главная страница форума без ложных утверждений о наличии категории.
- Переходы `/forum/?section=collaboration` и аналогичные обрабатываются форумом только после проверки включённой категории. Выключенные и удалённые категории не показываются.
- Прямые музыкальные команды, правила и ответы владельца имеют приоритет; локальный помощник и резервный режим без Cloudflare AI сохранены.
- Ссылки разрешены только если они реально есть в публичном меню либо относятся к опубликованному разделу; частные административные адреса и чужие домены отклоняются. Действие кнопки проверяет URL повторно.
- Никакие сообщения не отправляются самим DJ Velar; `/contacts/` — отдельная форма личного обращения.

## Тесты

- `node tests/test-site-navigation.mjs`: контакты, сотрудничество, новые разделы, выключенные категории, безопасность ссылок, приоритет ответов владельца и сохранение музыкальных команд.
- `npm test`: регрессионные проверки. GitHub Actions проверяет также Chromium и WebKit.

## Ограничения

Навигационный каталог не является полнотекстовым поиском по содержимому форума. Он ведёт к опубликованным разделам, но не утверждает о наличии конкретного обсуждения. Для автоматического поиска по реальным темам форума потребуется отдельный публичный поиск с проверкой их видимости. Новая отдельная страница должна быть добавлена в публичное меню; новый раздел главной страницы должен иметь видимый `section[id]` и заголовок.
