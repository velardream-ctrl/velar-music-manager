# RUN-170 — эмблема VELAR RADIO на старом iPad
Дата 17.11.2026.

## Дефект
На фотографии старого iPad видно только золотое свечение (взаимодействие с радио работает). Код CSS использовал только WebP для фона значка. Старые браузеры Safari (до iOS 14) не поддерживают WebP.

## Исправление
- Прежний утверждённый золотой логотип с радиокристаллом и текстом VELAR RADIO переведён из исходного 112×112 WebP в прозрачный 112×112 PNG с оптимизированной палитрой (64 цвета, 5306 байт). Новый файл: assets/velar-radio-icon-gold-bold.png; Git blob SHA 11d74b632c5012ff3afc0d6fc8fe2633b5ed313d.
- Обе каскадные декларации CSS-фона круглой кнопки используют PNG. Это надёжно даже когда WebP декодер отсутствует; современные браузеры видят тот же дизайн.
- Сервис-воркер включает PNG в офлайн-кэш; увеличена версия public cache v88 и style.css?v=78 для очистки старой Safari-разметки.
- Никаких изменений в радио, режимах свечения и автоматическом воспроизведении. Старые WebP в репозитории сохранены.

## Тесты
tests/test-radio-legacy-icon.mjs: PNG byte signature, размер/прозрачность, обе CSS-подложки PNG, SW allowlist/cache, версии HTML. Дополнительная регрессия test-release-radio.mjs и общая npm test.
