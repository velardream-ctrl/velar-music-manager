# Форум VELARDREAM «Созвездия»

Отдельная ветка `feature/velardream-constellations-forum`. В меню основного сайта ссылки на форум пока нет.

## Первая версия

- Четыре раздела: вопросы о сайте, идеи для песен, сотрудничество и обсуждение релизов.
- Открытое чтение тем и ответов, поиск среди загруженных тем, похожие заголовки при создании темы.
- Публикация после входа по ссылке на подтверждённый email. Email и данные авторизации в документы тем не записываются. В теме видно выбранное имя.
- Для визуальной проверки откройте `/forum/?demo=1` в статическом предпросмотре ветки. Деморежим не инициализирует Firebase. Созданные темы и ответы исчезают после обновления страницы.

## Подключение

1. Подготовить тестовый Firebase проект или Firebase Emulator, проверить разрешения форума с анонимным, неподтверждённым, подтверждённым и административным аккаунтами.
2. В Firebase Authentication рабочего проекта включить Email/Password и Email link, сверить разрешённый домен `velardream.com` и пройти реальную проверку письма. Тестировать возврат на `/forum/`, в том числе с другого устройства.
3. Сравнить текущие опубликованные Firestore Rules и индексы с репозиторием. Добавить только форумные правила и два индекса, дождаться готовности индексов. Не заменять текущие правила целиком без сравнения. Доступ к Studio по-прежнему ограничен существующим Google-админом.
4. Подтвердить чтение без входа, создание тем и ответов после входа, скрытие и восстановление тем и ответов через Studio → Форум, отсутствие доступа к приватным коллекциям Studio. Проверить список тем и форму на телефоне.
5. После приёмки добавить ссылку «Форум» в навигацию сайта. Затем можно добавить в VELAR подсказку со ссылкой на соответствующий открытый раздел. Сейчас помощник форум не читает.

До публикации проверить базовую модерацию и защиту от спама. Рабочий Firebase в рамках разработки ветки не менялся.

## Публикация по прямому адресу

Публичная навигация VELARDREAM не содержит ссылки. Для проверки дизайна и интерфейса открывается `/forum/?demo=1`, рабочая страница — `/forum/`. В Studio пункт «Форум» ведёт к модерации. Доступ проверяется по существующей роли администратора Studio, операции скрытия и восстановления разрешает Firestore. Для реальных тем, ответов и модерации нужно применить форумные правила и индексы к Firebase и подтвердить почтовый вход.

## Модерация · 18.11.2026

В Studio → Форум у тем и ответов есть скрытие, удаление с восстановлением и бан автора. Снять бан можно в списке заблокированных. Бан запрещает новые публикации. Для работы на сайте нужно применить обновлённые форумные правила Firebase.

## Управление разделами

В Studio → Форум → Разделы форума можно добавить раздел, указать название и иконку (символ или эмодзи), изменить порядок или скрыть раздел. Скрытый раздел убирается из меню и списка для создания тем, а ранее опубликованные темы остаются в общей ленте и доступны по прямым ссылкам. Сохранение раздела не меняет его идентификатор.

Для активации в рабочем Firebase замените только функцию `forumCategory` в опубликованных правилах на блок от `function forumSectionPath` до конца `match /velar_forum_sections/{sectionId}` из [firestore.rules](../firestore.rules). Следующая функция `forumPost` и остальные правила остаются на месте. После публикации правил проверьте создание раздела из Studio и появление в списке форума. Дополнительный составной индекс не нужен: список настроек использует только ограничение количества документов.
